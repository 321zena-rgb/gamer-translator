# Gamer Translator

A mobile-first website that turns what kids say while gaming into Out-of-Touch Adult English, and back again.

- Pick a game: Roblox, Minecraft, Brawl Stars, Fortnite, Call of Duty, Clash Royale, Genshin Impact, Star Rail, Among Us, or Any game.
- Choose "Just the facts" or the funny "Over the top" translation.
- **Record** listens live using the browser's built-in speech recognition (Chrome, Edge and Safari).
- **Upload** turns an audio or video recording into text on your own device with a small Whisper model. The model downloads once (about 40 MB) and no audio is sent to a server.

It's a single static page (`index.html`) hosted on GitHub Pages. No build step and no API keys.
