# Gamer Translator

A mobile-first website that turns what kids say while gaming into Out-of-Touch Adult English, and back again.

- Pick a game: Roblox, Minecraft, Brawl Stars, Fortnite, Call of Duty, Clash Royale, Genshin Impact, Star Rail, Among Us, or Any game.
- Game words and everyday slang are explained in plain English.
- **Transcribe** listens live using the browser's built-in speech recognition (Chrome, Edge and Safari).

It's a single static page (`index.html`) hosted on GitHub Pages. No build step and no API keys.
